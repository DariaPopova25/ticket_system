# Ticket System

**Ticket System** — pet-проект на Django для создания и обработки заявок о проблемах на сайте.

Проект решает важную проблему: заявки не теряются, а проходят понятный путь от создания до завершения. Их удобно создавать, делегировать нужному специалисту и обсуждать в комментариях. Всегда можно понять, на каком этапе находится заявка по её статусу и насколько она важна по приоритету. Благодаря этому роли не путаются, зона ответственности понятна, а проблема доводится до решения.

## Логика ролей

### Client

Клиент:
- создаёт заявку
- видит только свои заявки
- может писать комментарии только в своих заявках
- не может назначать исполнителя
- не может менять приоритет
- не может менять менеджерские и разработческие поля

### Manager

Менеджер:
- видит все заявки
- назначает разработчика
- меняет статус
- меняет приоритет
- заполняет `manager_notes`
- может комментировать заявки

### Developer

Разработчик:
- видит только назначенные ему заявки
- работает только со своими заявками
- меняет статус только в рамках разрешённых переходов
- заполняет `resolution_notes`
- может комментировать назначенные ему заявки

## Логика работы заявки

Стандартный сценарий:

`new -> pending_development -> in_progress -> pending_review -> done`

Также менеджер может отменить заявку:

`cancelled`

### Основные правила

- заявку создаёт только `client`
- менеджер назначает `developer`, выставляет приоритет и переводит заявку в работу
- разработчик не может работать с неназначенной ему заявкой
- разработчик не может выполнять менеджерские действия
- после статусов `done` и `cancelled` заявка становится закрытой и больше не редактируется и не комментируется
- назначить в `assignee` можно только пользователя с ролью `developer`
- для рабочих статусов обязательны `assignee` и `priority`
- разработчика можно снять только в статусе `new`

## Запуск через Docker

1. Клонировать репозиторий
2. Перейти в папку проекта
3. Создать `.env` на основе `.env.example`
4. Запустить проект
5. Открыть приложение в браузере

```bash
git clone https://github.com/DariaPopova25/ticket_system.git
cd ticket_system
cp .env.example .env
docker compose up --build
```

Приложение будет доступно по адресам:

- `http://127.0.0.1:8000`
- `http://localhost:8000`
